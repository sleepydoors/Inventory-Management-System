# Inventory Management System

Web-based inventory management application built with Flask and SQLite.

## Features

* User Authentication (Login & Logout)
* Inventory Management
* Room Management
* QR Code Generation & Scanning
* Activity Logs
* Excel Export
* Dashboard Statistics

## Tech Stack

* Python
* Flask
* SQLite
* Bootstrap 5
* SQLAlchemy

## Run Locally

```bash
pip install -r requirements.txt
python app.py
```
